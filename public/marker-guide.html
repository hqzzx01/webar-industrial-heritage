生成步骤

  1. 打开官方 Generator。
  2. 点击 Upload，选择一张内图，不要上传完整 marker 成品图。
  3. Pattern Ratio 保持 0.50，这是 AR.js 默认值，先不要改。
  4. 点击 Download Marker 下载 .patt 文件。
  5. 点击 Download Image 下载实际要打印或展示的 marker 图。
  6. 把 .patt 放到 public/assets/marker/，代码里对应替换路径。

为什么要简单

AR.js marker tracking 不是扫二维码。它需要识别清晰的黑色外框，再匹配内部图案。内图越复杂、越像二维码、越对称，越容易识别失败。先用这些简单黑白图跑通，再逐步美化。
